## Gotcha mới (nối tiếp 37 của log 09-14-14)

38. DOTween `Ease` có `Unset = 0` nên int serialize lệch 1 so với LitMotion: 0 → 5, v → v−1. Default DOTween là
    OutQuad. `Append` của DOTween = cuối cả sequence, port sang LitMotion phải `Insert` với vị trí tính tay.
39. `compilecheck.sh` gộp asmdef nên namespace `LogosSDK.Tween` che kiểu `Tween` của DOTween (CS0118) trong lúc
    migrate dở — chỉ hết khi file dùng DOTween cuối cùng được port.
40. Unity xoá `Temp/` khi thoát → ledger, script, kết quả test để ở `.git/sdd/`.
41. Sửa file bằng Python/sed trên Windows chuyển CRLF → LF; git normalize nên diff sạch, nhưng `ProjectSettings.asset`
    nên khôi phục CRLF cho khớp Unity.
42. `SafeAreaFitter.Apply` return sớm khi safe area rỗng **trước** khi ghi anchor → sizeDelta bake còn nguyên một
    frame. Nên áp anchor full màn ở nhánh rỗng và không cache giá trị rỗng.
43. Canvas Overlay: quad to hơn màn **không tốn fill-rate** (GPU clip), đừng tính "overdraw" cho rect quá khổ.
44. `Screen.safeArea` chỉ né được tai thỏ; `androidResizeableActivity` vẫn cho split-screen đưa khung ngang.
45. `m_LocalEulerAnglesHint` chỉ là số hiển thị; xoay thật nằm ở `m_LocalRotation` (quat). `snow` chính hint −90
    nhưng quat identity. Với Shape Sphere góc xoay vô nghĩa; Cone phun theo +Z local, X+90 = xuống.
46. Shader Standard Built-in (fileID 10720) trong project URP = hồng. Material URP tự viết: chép template ở
    `Library/PackageCache/com.unity.render-pipelines.universal@*/Runtime/Materials/`, giữ header MonoBehaviour
    `version: 10`.
47. Regex đọc prefab: `fileID` có thể **âm** (sprite trong sheet). `\d+` bỏ sót → dump báo "không sprite" sai.
48. Parser YAML tay: phần tử list `- x` cùng thụt lề với key cha → phải coi là con của key.
49. Unity MCP "Connection revoked" cần user bật lại ở Project Settings → AI → Unity MCP; không có thì chỉ kiểm
    được ngoài Unity (Roslyn, dump file).
